How to use this template
- Copy this file into content/guides/ar/ (Arabic) or content/guides/en/ (English).
- Rename it: the file name becomes the URL, so use lowercase latin letters and dashes,
  e.g. content/guides/ar/youtube-title-tips.md -> /ar/guides/youtube-title-tips/
- Fill in the front matter above, delete this block, write the guide, then set draft: false.
- translation: the file name (without .md) of the same guide in the other language, or "".
- affiliates: ids from AFFILIATES in src/config.js that fit this guide, or [] for none.
